# GoldRift's Patches

Morphe patches for apps I use.

## Patchable Apps

| App | Version | Patch |
|-----|---------|-------|
| Strong | 6.2.2 | Unlocks Pro |

## 🚀 Usage

1. Install [Morphe Manager](https://morphe.software)
2. Add this repo as a patch source: `https://github.com/GoldRift/morphe-patches`
3. Select your app, apply the patch, and build

## 🧑‍💻 Development

```sh
./gradlew buildAndroid           # build patches
```

Work on the `dev` branch. Merge to `main` for stable releases.
